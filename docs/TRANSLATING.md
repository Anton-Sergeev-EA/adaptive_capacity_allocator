# Как добавить или исправить перевод

Интерфейс есть в трёх местах. Порядок языков везде один: русский (основной), затем по числу говорящих в мире —
English, 中文, हिन्दी, Español, Français, Deutsch, Italiano.

## 1. Консольная программа `acalloc`

Файлы: [`apps/i18n.hpp`](../apps/i18n.hpp) и [`apps/i18n.cpp`](../apps/i18n.cpp).

- Чтобы **исправить** текст, найдите строку в таблице `kTable` в `i18n.cpp`. Каждая запись — восемь строк в порядке
  `ru, en, zh, hi, es, fr, de, it`. Метки `{0}`, `{1}` подставляются автоматически: их нужно сохранить, порядок
  внутри фразы можно менять.
- Чтобы **добавить язык**:
  1. добавьте его в массив `kLanguages` в `i18n.hpp` и увеличьте размер массива;
  2. добавьте по одной строке в каждую запись `kTable` (компилятор не даст пропустить запись);
  3. при необходимости укажите разделитель разрядов и десятичный разделитель в `thousands_separator()` и `decimal_comma()`;
  4. добавьте код языка в цикл тестов в `CMakeLists.txt` и в шаг «Demo in every language» в `.github/workflows/ci.yml`.

Проверка:

```bash
cmake --build build && ./build/acalloc --lang <код> && ./build/acalloc --lang <код> --help
```

## 2. Веб-страница

Файл [`docs/index.html`](index.html): объект `T` в скрипте внизу страницы, по одному блоку на язык.
Новый язык добавьте также в массивы `LANGS` и `LOCALE`.

## 3. README

`README.md` (русский) — основной. Переводы лежат рядом: `README.<код>.md`. Строка ссылок на языки в начале каждого
файла должна перечислять все языки в одном порядке.
