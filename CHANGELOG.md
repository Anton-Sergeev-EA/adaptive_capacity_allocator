# Журнал изменений · Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [2.0.0] — 2026-10-01

### Ядро
- **Нет фоновых потоков.** Версия 1.0 запускала отдельный поток на каждый вектор (10 000 векторов = 10 000 потоков).
- **Часы больше не опрашиваются на каждой вставке.** Контейнер считает вставки локально и сообщает телеметрии раз в
  64 вставки и при каждом решении о росте. Непрерывный поток из 1 000 000 `int`: ~9 мс вместо ~40 мс.
- **Простой действительно распознаётся.** В 1.0 проверка простоя никогда не срабатывала в момент перераспределения;
  теперь первая вставка после паузы дольше `idle_reset` приводит к агрессивному росту.
- Буферы меньше `min_adaptive_capacity` (1 024) всегда удваиваются: в 1.0 рост ×1,1 включался уже с 8 элементов и
  давал лавину мелких перераспределений.
- `growth_policy`: коэффициенты, пороги скорости, окно измерения, порог простоя, частота отчётов и минимальная ёмкость
  задаются пользователем и проверяются (`validate()`).
- `allocation_telemetry::decide()` возвращает ёмкость, стратегию и скорость; `snapshot()` — сводную статистику.
- `adaptive_vector`: `insert`, `emplace`, `erase`, `pop_back`, `resize`, `assign`, конструкторы из размера,
  значения, диапазона и списка инициализации, копирование, `swap`, сравнения, обратные итераторы, `stats()`, `telemetry()`.
- Заголовок перенесён в `include/adaptive/adaptive_allocator.hpp`; старый `adaptive_allocator.hpp` в корне оставлен для совместимости.

### Исправления
- Вектор после перемещения из него (`std::move`) падал при следующем `push_back` (нулевой указатель телеметрии).
- `adaptive_allocator::operator==` сравнивал указатели телеметрии, хотя `is_always_equal` объявлен `true`.
- Не хватало `#include <cstdint>` для `std::int64_t`.
- Тесты использовали `assert`, который в Release-сборке (`NDEBUG`) отключается: CI в Release ничего не проверял.

### Интерфейс на 8 языках
- Программа `acalloc`: демонстрация на четырёх сценариях и сравнение с `std::vector`.
- Языки: русский (основной), English, 中文, हिन्दी, Español, Français, Deutsch, Italiano; автоопределение по языку системы,
  `--lang`, `ACALLOC_LANG`; местные форматы чисел (включая индийскую группировку разрядов для хинди).
- Интерактивная веб-страница с симулятором (`docs/index.html`, публикуется через GitHub Pages).
- README на всех 8 языках.

### Инфраструктура
- `cmake --install` и `find_package(AdaptiveAllocator)`; цели тестов и программ не собираются, если библиотека подключена
  через `FetchContent`.
- CI: Linux (GCC/Clang × Debug/Release × C++17/20), macOS, Windows MSVC, ASan+UBSan, TSan, проверка установки, clang-format.
- Docker-образы собирают и запускают тесты и `acalloc`.
